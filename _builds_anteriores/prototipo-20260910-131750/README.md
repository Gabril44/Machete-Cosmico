# Machete Cósmico

Primer prototipo en Lua + LÖVE2D.

## Controles
- WASD: movimiento
- Espacio: machetazo
- Shift izquierdo: dash
- F: Berserk cuando la barra de Furia está llena

## Qué incluye
- Movimiento cenital
- Machete con hitbox
- Knockback
- Aliens que entran desde los bordes
- Vacas que pueden ser abducidas
- Barra de vida y furia
- Berserk básico
- Escenario de chacra placeholder
