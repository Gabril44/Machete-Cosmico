# 🛸 Machete Cósmico — Demo Alpha

¡Un gaucho, un machete y una invasión alienígena! 👽🧉

**Machete Cósmico** es un juego de acción 2D estilo hack and slash, desarrollado con LÖVE2D.

### 📦 Instalación
1. Descargá el ZIP desde **Assets**.
2. Extraé los archivos.
3. Ejecutá el `.exe` y ¡a jugar!
